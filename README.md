# Aditi Thakare — Portfolio

A cinematic, premium portfolio website built with React + Vite + Tailwind CSS + Framer Motion.

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

### Production Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Deployment

### Vercel
1. Push to GitHub
2. Import repo in [vercel.com](https://vercel.com)
3. Deploy — zero config needed

### Netlify
1. Push to GitHub
2. Import repo in [netlify.com](https://netlify.com)
3. Build command: `npm run build`
4. Publish directory: `dist`

## Tech Stack
- React 18
- Vite 5
- Tailwind CSS 3
- Framer Motion 11
- Playfair Display + Montserrat (Google Fonts)
